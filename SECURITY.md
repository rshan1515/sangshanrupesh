# Security Policy

## Reporting a Vulnerability

If you find a security vulnerability, please report it privately via GitHub's private vulnerability reporting feature or email the repository owner.

## Responsible Disclosure

- Please do not create public issues for security vulnerabilities.
- We will respond to your report as soon as possible and work to resolve it promptly.

## Additional Security Practices

- This repo does not store or process sensitive data.
- No secrets, API keys, or passwords should be committed.
