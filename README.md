## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm 8+

### Installation

```bash
# Clone the repository
git clone https://github.com/rshan1515/sangshanrupesh.git
cd sangshanrupesh

# Install dependencies
npm install

# Run linting
npm run lint

# Run tests
npm test
```
